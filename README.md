# TRAXIONAR — Landing Page Oficial

Sitio web y landing page oficial del ecosistema de software empresarial **TRAXIONAR** (by WERNECKE).

## 🚀 Ecosistema de Soluciones

- **Traxionar TPV Multi-Sucursal**: Punto de Venta ágil, facturación electrónica AFIP, control de caja y cierre Z, catálogo/inventario, lotes y vencimientos PEPS, compras multimoneda, logística, clientes/cuentas corrientes, presupuestos PDF, Carta Digital QR e integración con Mercado Pago Point/QR.
- **Partrax**: Gestión integral de playas de estacionamiento, cocheras y garajes con mapa interactivo en tiempo real y control por patente.
- **CaseQR**: Control de acceso y asistencia de personal mediante códigos QR en modo Kiosco PWA, portal del empleado y bitácora de guardia/seguridad.
- **TARS CRM**: Software CRM y gestión de laboratorio técnico para tiendas de telefonía móvil y servicio técnico con trazabilidad por IMEI.
- **Lander TPV**: Sistema POS en la nube multi-tenant para minimarkets, autoservicios y almacenes.
- **Traxionar Gym**: Plataforma SaaS para administración de socios, planes de membresía, rutinas de entrenamiento y clases fitness.

## 🛠️ Tecnologías

- HTML5 semántico con marcado estructurado **Schema.org JSON-LD** (SEO técnico y Core Web Vitals).
- **Tailwind CSS** (vía CDN) + diseño responsivo y modo oscuro nativo (`#050505`).
- **FontAwesome 6** para iconografía.
- Tipografía **Inter** (Google Fonts).

## 🌐 Despliegue

Los archivos estáticos (`index.html`, `robots.txt`, `sitemap.xml`) están listos para ser servidos en cualquier servidor web (Nginx, Apache, Vercel, Netlify, GitHub Pages, etc.).
